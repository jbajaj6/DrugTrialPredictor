# B19 structural evidence audit

This module audits development evidence and makes a reproducible review sample. It does not infer favorable direction, clinical benefit, significance labels, drug identity, or model performance. An unknown p-value, result, role, or direction stays unknown.

Use the pinned B17 `anamnesis_grade_b17_full_v3_2026-11-25` directory only. The CLI verifies its hard-pinned manifest SHA256, all eight output hashes and report hash; it checks the report's selected count of 8,414 and matches B17's eight input hash declarations to their upstream manifests. Upstream manifest hashes and source commits are recorded. Upstream value files are not reopened; independently rehashing them belongs to the provenance audit.

Before opening any result values, the CLI projects only NCT/version/public-date columns from the selected universe and all seven preserved child tables, including serious-event statistics. Missing/invalid dates, any 2024+ public availability date, duplicate selected trials, outside-universe child keys, or child public dates differing from the selected exact version abort the run. `anticipated_posting_date` is prospective metadata, not public availability. It does not replace the source public date. The complete pinned universe is checked even for a pilot.

Run from `phase-by-phase/`, with `PYTHONPATH=src`:

```sh
PYTHONPATH=src ../.venv/bin/python -m pytest -q tests/test_audit_b19.py
PYTHONPATH=src ../.venv/bin/python -m phase_by_phase.audit_b19 --out data/processed/b19_pilot_NEW --limit-trials 40 --sample-size 40
# Coordinator inspects the pilot before authorizing the full replay.
PYTHONPATH=src ../.venv/bin/python -m phase_by_phase.audit_b19 --out data/processed/b19_full_NEW
```

Every output directory must be fresh. Existing source files and outputs are never overwritten. Output files are `trial_evidence.parquet` (one exact trial/version), `primary_evidence.parquet` (one distinct nonmissing primary outcome key), `sample_trials.parquet`, `sample_raw.jsonl`, `report.json`, and `manifest.json`. The JSONL contains full raw primary title, description, time frame, groups, arms/roles, measurements, analyses (including method, p, CI and comments), analysis-group IDs, and public dates. Raw children are linked by exact NCT/version/outcome/group/analysis keys without relational multiplication. Unresolved primary-scoped children are retained separately. Duplicate source keys are preserved in raw review material and explicitly reported as ambiguous, not arbitrarily resolved.

The measurement natural key includes outcome, class, category, measurement ordinal, and group ID. Multiple rows per result group can be legitimate strata; the audit reports these separately. Numeric-group counts use finite parsed numbers from nonduplicate complete measurement keys linked to nonduplicate group keys; they do not pool estimates or infer effect direction. All natural-key duplicate/missing/orphan counts are reported. Missing primary-key rows are counted at trial level, never fabricated into an identified endpoint. Full original primary rows, including malformed keys, remain in sampled raw material.

The report provides independent coverage counts and cumulative funnels in their stated order, separately for trial and primary-outcome denominators. The latter is an availability funnel, not an efficacy eligibility rule. Primary outcomes are counted independently from child multiplicity. Exact trimmed/casefolded group/arm labels establish candidate bijections only; clinical identity remains unverified. Comparator roles require exactly one structured experimental arm and one active/placebo comparator. Analysis contrast availability requires two explicit distinct result-group IDs and corresponding roles. Multiple primary outcomes/analyses remain explicit multiplicity concerns. P parsing retains numeric bounds and qualifiers, supports scientific notation, rejects malformed/out-of-range probabilities, and never applies a significance threshold.

The `tested_non_inferiority` Boolean and `non_inferiority_type` enum are separate source facts, retained raw and normalized per analysis. Flags are `true`, `false`, or `missing` (unexpected values are `invalid`). Exact enums map to `noninferiority` (`NON_INFERIORITY`), `equivalence` (`EQUIVALENCE`), `noninferiority_or_equivalence` (`NON_INFERIORITY_OR_EQUIVALENCE` or `NON_INFERIORITY_OR_EQUIVALENCE_LEGACY`), `superiority` (`SUPERIORITY`), `superiority_or_other` (`SUPERIORITY_OR_OTHER` or its legacy variant), `other` (`OTHER`), `missing`, or `unknown_enum`. A combined enum never distinguishes NI from equivalence. Superiority/other values make no NI or equivalence claim; missing flags remain unknown. The report counts every primary analysis by raw enum, normalized enum, flag, consistency state, and flag-by-enum combination, separately from endpoint-level availability counts. Endpoint lists preserve all observed states; summary fields do not resolve disagreement or establish efficacy.

Cross-field diagnostics mark true flag plus explicit `SUPERIORITY`, or false flag plus explicit `NON_INFERIORITY`, as conflicts. True flag plus `EQUIVALENCE`, broad superiority/other, or other enum is a review state; false flag plus combined NI/equivalence enum is also a review state because equivalence remains possible. Missing/unknown fields cannot establish consistency. All other observed pairs have `no_direct_conflict_observed`, which is not clinical verification. The final funnel's explicit-false Boolean count describes that flag alone, not absence of NI/equivalence or eligibility for a new label. The initial pilot exposed incorrect treatment of any nonempty enum as NI; targeted repair round 1 corrects that classification without changing source data or the immutable pilot.

Sampling defaults to **seed 20261127 and 120 unique actual trials**. Sampling axes are B17 reason, p presence, structured parameter types, exact structured unit family, public-result era, arm mapping, and analysis contrast. No outcome prose is parsed to construct families. Known exact units map to percent, time, count, or score; remaining units are `other_structured_unit`. Parameter types are normalized structured values, not inferred endpoint families. First cover B17 reason codes, p presence, then eras, in that axis order and lexical value order. Next cover remaining axis/value marginals ordered by ascending universe frequency then axis/value. Each uncovered marginal selects the smallest SHA256(`seed|NCT|version`) among its trials. Then fill by round-robin over composite strata ordered by SHA256(`seed|stratum`), using the same trial hash ordering. Stratum IDs are `b19_` plus the first 16 hex digits of SHA256 of the semicolon-joined values in the sampling-axis order above; dimensions remain readable in trial columns. Stop at the requested size or universe size. Return sorted unique trial keys. When all margins cannot fit, universe/sample distributions expose uncovered values. It is a review sample, not a probability sample or unbiased clinical estimate.

Pilot selection uses the first N sorted exact trial keys; it is an engineering replay, not representative coverage. Full execution and independent evaluation are coordinator-owned. Synthetic checks establish engineering behavior only. Scientific rule design, new labels, class support, chronology checks for future predictors, clinical criticism, and model fitting require separately preregistered tasks. This audit establishes no new estimable supported-benefit target.
